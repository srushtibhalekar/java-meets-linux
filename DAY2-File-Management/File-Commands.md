# 🐧 Day 2 — File & Directory Management

## 📁 mkdir — Create Directory

Creates a new directory.

```bash
mkdir projects
```

## 📂 cd — Change Directory

Moves into a directory.

```bash
cd projects
```

## ↩️ cd .. — Move Back

Moves to the parent directory.

```bash
cd ..
```

## 📄 touch — Create File

Creates an empty file.

```bash
touch notes.txt
```

## 📋 cp — Copy File

Creates a copy of a file.

```bash
cp notes.txt backup.txt
```

## 🚚 mv — Move / Rename

Moves or renames a file.

```bash
mv notes.txt linux-notes.txt
```

## 🗑️ rm — Remove File

Deletes a file.

```bash
rm linux-notes.txt
```

## 📂 rmdir — Remove Directory

Removes an empty directory.

```bash
rmdir projects
```

## 🎯 Day 2 Mission

**Create it. Copy it. Move it.
Rename it. Remove it.**

## 🧠 Commands Learned

* `mkdir`
