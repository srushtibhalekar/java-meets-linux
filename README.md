# 🐧 30 Days of Linux

A **30-Day Linux Challenge** focused on building practical Linux skills through daily hands-on command-line practice.

The challenge covers Linux fundamentals, file management, permissions, processes, networking, Bash scripting, system administration, SSH, Git, and automation.

---

## 🎯 Challenge Goal

The goal is to become comfortable working with Linux from the terminal and develop practical skills that are useful for development, servers, DevOps, and system administration.

## 🚀 Final Project — Day 30

Build a **Linux System Information & Backup Script**.

The script should:

* Display system information
* Display current user
* Display hostname
* Display kernel information
* Display memory usage
* Display disk usage
* Display IP information
* Create a backup
* Store the backup with a timestamp

Example:

```text
===== SYSTEM INFORMATION =====

Hostname:
Username:
Operating System:
Kernel:
Memory:
Disk Usage:
IP Address:

===== BACKUP =====

Backup Started...
Files Found:
Backup Created:
Backup Location:
```
